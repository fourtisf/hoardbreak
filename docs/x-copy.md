# @TheDragonjob — copy templates

The account **is** the game, not the person who built it. It talks the way the
lair talks: present tense, second person, short sentences, no adjectives doing
work a number could do better.

## How to use this file

**Every fenced block below is a finished post. Copy it exactly — the blank lines
are part of it.**

On X a blank line is the only paragraph break there is, and it does most of the
pacing work: it is the pause before the number lands. Copy three lines without
the gaps and you get a mumbled sentence; copy them with the gaps and you get
three beats. That is the difference between a post that is read and a post that
is scrolled past.

So the postable text sits in fenced blocks rather than in prose or quotes: a
fence keeps the spacing byte for byte, and puts nothing at the front of a line
for you to pick back out again. Anything outside a fence is instruction and is
never meant to be posted.

Fill any `<placeholder>` from the day's actual run before posting. The numbers
are the product, and every one of them is real and checkable in-game.

## The never-write list

1. **First-person dev talk.** No "I built", "I made this", "my little game".
   The wyrm does not have a developer.
2. **"Check out" / "link in bio" / "drop a follow".** Ask for the thing itself,
   or ask for nothing.
3. **Hype adjectives.** No *insane*, *crazy*, *addictive*, *revolutionary*. A
   number is louder.
4. **Emoji as decoration.** One, at most, and only where the game itself uses
   one (☠ ⚔ 🗝 💰). Never a row of them.
5. **Explaining the joke.** State the rule and stop. The cruelty lands on its
   own.
6. **Walls of text.** A blank line between every beat. Two lines with no gap
   between them had better be one thought.

meaning on its own — put the game's own noun beside it the first time it appears

video script, or half the room will say one thing and half the other.

### The extra never-write list, for these posts only

Everything in the list at the top still applies. These are additional.

1. **No price, ever.** No targets, no floors, no "still early", no charts, no
   market cap. The account does not know where the price is going, and saying so
   anyway is how people lose money on your word.
2. **No manufactured urgency.** No countdowns to "the last chance", no "you will
   regret". The daily reset is real urgency; nothing else has to be invented.
3. **No "utility" hand-waving.** Say the formula. If a thing is not built yet,
   say *not built yet*.
4. **No engagement farming.** No "like + RT for whitelist", no reply-to-enter.
5. **Never post the address as an image only.** People retype from screenshots
   and land on a fake. Text, every time, so it can be copied exactly.

## Length and spacing

One breath per line. If a line needs a comma to survive, it wants to be two
lines.

A blank line between every beat — that is the pause before the number lands, and
it is the difference between three beats and one mumble. Two lines with no gap
between them had better be one thought.

Posts run three to six beats. Anything longer is a thread, and a thread needs a
reason beyond having more to say.
